# Nature Theme Vision Therapy

A React + TypeScript + Vite application for displaying and reading stories with adjustable font size, designed for
vision therapy.

## Features

- Browse and select stories
- Adjustable font size for accessibility
- Clean, nature-inspired UI using Tailwind CSS

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- pnpm (or npm/yarn)

### Installation

```sh
pnpm install
```

### Development

```sh
pnpm dev
```

Open [http://localhost:5173](http://localhost:5173) to view the app.

### Build

```sh
pnpm build
```

### Lint

```sh
pnpm lint
```

## Project Structure

- `src/` - Source code
  - `components/` - React components (`Controls.tsx`, `StoryDisplay.tsx`)
  - `App.tsx` - Main app component
  - `main.tsx` - Entry point
- `public/stories.json` - Stories data
